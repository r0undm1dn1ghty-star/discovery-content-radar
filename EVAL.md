Что проверено в этой сборке и как убедиться, что она работает у тебя. Дата: 13.10.2026.

## Метод

Каждый бэкенд прогнан на живых данных из РФ, без VPN. Оригинальные анализаторы (`analyze_posts.py`) не переписывались — это контрольная: если они принимают данные фетчеров и выдают аутлаеров, сборка совместима с оригиналом.

## Как повторить

```bash
# TikTok (без ключей)
python .claude/skills/tiktok-research/scripts/fetch_tiktok.py --usernames nasa --limit 15 --days 45 --output run/raw.json
python .claude/skills/tiktok-research/scripts/analyze_posts.py --input run/raw.json --output run/outliers.json

# YouTube (без ключей)
python .claude/skills/youtube-research/scripts/find_outliers.py --channels @veritasium @mkbhd --per-channel 25 --min-z 2.0 --output-dir run/
```

Критерий успеха: `outliers.json` непустой, у топового видео счётчики живые (не нули), отчёт собирается без исключений.

## Совместимость с оригиналом

Схемы данных фетчеров нормализованы под схемы оригинальных `analyze_posts.py`. Проверка: TikTok-анализатор оригинала принял данные нового фетчера и выдал аутлаеров без правок анализатора (потребовалась только защита от строк-чисел, которую API отдаёт сам по себе).
